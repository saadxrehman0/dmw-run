## Follow-up (25 Nov 2026, late): Tadawul fetcher and the Argaam lock flag

it a Saudi route). It drives a visible browser window: a hidden one gets "Access Denied". The list
page's own service works again, so one call lists a day's filings with their filing times (Riyadh
time), and each filing's Element/Explanation table comes back as rows. The 24 Nov window
(23 Nov 9:00 to 24 Nov 10:30 PKT) gave 24 filings with bodies in 13 seconds.

The Argaam paywall flag was wrong: `range` mode skipped every "Argaam Special" article, but that
is only Argaam's byline. Real locks show a teaser and a subscribe box (`.restricted-article`); on
the 25 Nov list page 8 of 16 Argaam Special rows were locked. `argaam_fetch.py` now flags `lock`
from the article page, and `special` no longer means skip. The same test found a bug in its window
search (an ID gap longer than 12 was read as "before the window", so the Mac run returned 0 items);
the probe now looks 60 IDs further first.
