## S1 Content (9:00): news sweep, TASI and Global bullets, the news Doc, the pick card

Task files: {REPO}/tasks/task-01-evening-news, task-02-tasi-writeup, task-05-global-writeup,
task-06-morning-news (SKILL.md each), with rules/news-selection.md, arabic-rules.md, global-tasi.md,
argaam.md and news-doc.md. The weekly schedule and ANB Rough no longer apply (team offboarded,
25 Nov 2026). Where a task file says to use the built-in browser, WebFetch or saudiexchange.sa,
use the scripts below instead: this session has no browser and no WebFetch, and Saudi Exchange
blocks scripted access (25 Nov 2026). The shell here may be PowerShell: quote paths with spaces.

1. News since the previous edition ({PREV_EDITION}), in one call (about 3 minutes):
   `{PY} {REPO}/scripts/argaam_fetch.py range --start "{PREV_EDITION} 09:00" --end "<end>" --out "{RUN}/news/argaam.json"`
   with <end> = "{EDITION} 09:00" in a replay, else the current PKT time ("YYYY-MM-DD HH:MM").
   Each item has id, headline (h), pub_pkt and up to 1,500 characters of body. Skip items with
   "special": true (Argaam Special, paywalled; rules/argaam.md). Argaam's company disclosures
   stand in for Tadawul filings. Economic items Argaam does not carry (SPA, GASTAT, SAMA): use
   WebSearch, within the same window.
2. Triage the headlines with scripts/triage.py (write them one per line to {RUN}/news/headlines.txt),
   drop items already used (the previous edition's news/NEWS.json in its run folder, or the
   previous published decks in {DAY}/prev/), and write {RUN}/news/candidates.json in the shape
   write_news_doc.py documents, Include and Maybe tiers in proposed rank order (news-selection.md).
   Every figure in an item comes from its article body; nothing from memory.
3. Write the TASI and Global bullets (EN and AR; global_calc.py and the data file for figures;
   WebSearch only for the Global story, within the window), and run check_ar_text.py on the AR.
4. `write_news_doc.py --cand candidates.json --batch {RUN}/news/doc_calls.json --md {RUN}/news/doc_preview.md`,
   send the two Claude Docs calls, and save the Doc link to {RUN}/news/doc_url.txt.
5. Export the Doc (markdown), `pick_card.py card --doc DOC.md --url <link> --out {RUN}/news/card.json`,
   then `gates.py open --run "{RUN}" --id pick --kind pick --card "{RUN}/news/card.json"`.
Result ok once the gate is open. The pick itself is S3's job.
